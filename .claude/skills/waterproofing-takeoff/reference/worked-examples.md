# Worked examples — calibration anchors

Real Leading Edge takeoffs already completed, used to sanity-check a new number. A
typical single-dwelling LE home lands **~$6,600–$7,800**. If a new takeoff for a
comparable house is well outside that band, re-check the wet-area count and floor areas
before presenting — the usual cause is over-counting wet areas (tiled robes/halls
treated as membraned) or a floor-area error.
